# Imagens do Prime Projetos 3D

Coloque nesta pasta as imagens utilizadas pelo site.

## Organização sugerida
- `categorias/` — capas e imagens das categorias STL
- `bonus/` — imagens dos materiais bônus
- `interface/` — logotipo, ícones e imagens gerais

Use nomes de arquivos simples, em minúsculas e sem espaços (por exemplo, `logo-prime.png`).
Para exibir uma imagem no site, utilize o caminho público correspondente, como `/images/logo-prime.png`.

Este arquivo mantém a pasta `public/images` no Git até você adicionar as imagens.
