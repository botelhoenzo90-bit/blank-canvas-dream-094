# Imagens das categorias — Prime Projetos 3D

Coloque nesta pasta as imagens quadradas das categorias da biblioteca.

## Padrão recomendado
- Formato: WebP ou PNG
- Proporção: 1:1 (quadrada)
- Sem textos ou marcas d'água
- Use nomes em letras minúsculas, sem acentos e com hífens.
